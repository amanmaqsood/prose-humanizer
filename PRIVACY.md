# Privacy

Prose Humanizer contains local instruction files and an optional local pattern-lint command. The repository does not collect, transmit, sell, or retain user content or telemetry.

The optional `profile` command reads only the files explicitly named by the user. Its JSON output contains source basenames, source types, SHA-256 hashes, word counts, feature-group evidence weights, and derived writing features. It does not contain the source passages. Prose Humanizer does not search parent or neighboring folders for voice samples.

Local benchmark ballots may contain source and candidate text because a human rater must compare them. They are created only at the path the user supplies and are not uploaded by this project.

Your chosen AI assistant may process content under its own privacy policy. Review that product's settings and policies before submitting sensitive material.
